# Examples

Sanitized research-record examples, one per file. Both use the fictional target
`example-protocol`. They show the structured record shape and a realistic
research arc. They are examples, not reports: no client secrets, no private
source, no unreported findings from any real target.

- [record-001-hypothesis-and-test.md](record-001-hypothesis-and-test.md) -- a
  record where a hypothesis is formed and a test is designed.
- [record-002-result-and-decision.md](record-002-result-and-decision.md) -- a
  follow-up record where the result comes in and a decision is made.

Together they show how two records in the same namespace build on each other,
which is the cross-session continuity this project depends on.
